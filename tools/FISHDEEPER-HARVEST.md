# Как да ми дадеш дълбочините от твоя логнат Chrome

Аз нямам достъп до браузъра на твоя компютър. Логинът ти е само при теб.

## Вариант A — Console (1 минута)

1. Отвори https://maps.fishdeeper.com/bg-bg (вече логнат).
2. Отвори един язовир (напр. Огоста), за да се заредят картите.
3. F12 → Console.
4. Пераш целия файл `fishdeeper-harvest-console.js` и Enter.
5. Сваля се `fishdeeper-bg-depths.json` — качи го тук в чата.

Координатите в файла съвпадат с водоемите (waterId / lat,lon) — аз ги закачам към нашата карта.

## Вариант B — само token

1. F12 → Network.
2. Кликни върху водата на Огоста.
3. Намери заявка `waters/depth?...&token=XXXX`.
4. Копирай само `XXXX` (не паролата) и го прати в чата.
